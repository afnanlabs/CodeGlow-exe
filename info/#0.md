My extension idea is:

[CodeGlow
CodeGlow is a Visual Studio Code extension that enables developers to manually highlight arbitrary code regions and persist those highlights across sessions.

Problem
Developers and students frequently use comments to explain code while learning, reviewing, or documenting projects.
However, comments do not always clearly identify the exact code region they describe
When revisiting code weeks or months later, it becomes difficult to determine which specific lines a comment was originally referring to.
CodeGlow solves this problem by allowing developers to visually highlight code regions and maintain that visual connection over time.
The goal is to preserve the relationship between explanations and the code they describe.

Product Philosophy

CodeGlow is not a note-taking application.
CodeGlow is not a documentation platform.
CodeGlow is not an AI assistant.
Developers should continue using standard code comments:

```js
// explanation

/*
multi-line explanation
*/
```

CodeGlow's responsibility is:
"Visually bind existing comments to the code they explain."

Target Audience

- Programming students
- Self-taught developers
- Technical educators
- Documentation writers
- Developers performing code reviews

Final Scope

Feature 1 — Manual Code Selection
Users can select any arbitrary code region.
Feature 2 — Highlight Command
Users can trigger highlighting through:

- Right-click context menu
- Command Palette
  Feature 3 — Color Selection

- Green
- Blue
  Feature 4 — Visual Highlighting
  Selected code receives a colored background decoration.
  Feature 5 — Persistence
  Highlights are automatically saved.
  Feature 6 — Session Restoration
  Highlights are restored when:
- VS Code restarts
- Project reopens
- File reopens
  Feature 7 — Unlimited Highlights
  Users can create multiple highlights within the same file.
  Feature 8 — Remove Highlight
  Users can remove individual highlights.
  Feature 9 — Edit Highlight Color
  Users can change an existing highlight color without recreating the highlight.
